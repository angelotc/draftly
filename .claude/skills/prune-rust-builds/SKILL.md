# Prune Rust builds

Cargo `target/` folders are regenerable build output and are usually the biggest disk hogs
(MapleClassic alone reached ~41 GB: `debug` ~26 GB, `package-runtime` ~12 GB, `release` ~2.4 GB).

## 1. Measure

Report free space and every Cargo build dir (Cargo writes `CACHEDIR.TAG` into each `target/`):

```powershell
"{0:N2} GB free" -f ((Get-PSDrive C).Free/1GB)
Get-ChildItem C:\Users\angel\Documents\projects -Recurse -Force -Depth 4 -Filter CACHEDIR.TAG -ErrorAction SilentlyContinue |
  Where-Object { $_.Directory.Name -eq 'target' } |
  ForEach-Object {
    $s = (Get-ChildItem $_.Directory.FullName -Recurse -File -Force -ErrorAction SilentlyContinue | Measure-Object Length -Sum).Sum
    [pscustomobject]@{ GB = [math]::Round($s/1GB,2); Path = $_.Directory.FullName }
  } | Sort-Object GB -Descending | Format-Table -AutoSize
```

For a per-subfolder breakdown of one target (to choose a lighter prune), list its
top-level dirs with sizes (`debug`, `release`, `package-runtime`, ...).

Also worth reporting (but rarely worth deleting): `~/.cargo/registry` (~1.6 GB, shared crate
cache) and `~/.rustup/toolchains` (remove only unused toolchains with `rustup toolchain uninstall`).

## 2. Confirm with the user

Show the table and recommend. Options:
- **Full:** delete each whole `target/` (biggest win; next build is a slow full rebuild).
- **Light:** delete only `target/debug` and `target/package-runtime`, keep `target/release`.

Note: MapleClassic's `target/package-runtime` holds packaged runtime output — it's
regenerated by the packaging script, but mention it before deleting.

Close any running builds, `cargo watch`, rust-analyzer-heavy editors, or the app itself first,
or files may be locked.

## 3. Delete and report

```powershell
$before = (Get-PSDrive C).Free
foreach ($t in @('<path1>\target', '<path2>\target')) {
  try { Remove-Item $t -Recurse -Force -ErrorAction Stop; "deleted $t" }
  catch { "FAILED $t : $($_.Exception.Message)" }
}
"Freed {0:N2} GB, now {1:N2} GB free" -f (((Get-PSDrive C).Free-$before)/1GB), ((Get-PSDrive C).Free/1GB)
```

(`cargo clean` in each project works too, but is slower and needs a valid Cargo workspace.)
